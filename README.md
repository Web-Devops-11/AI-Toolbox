# 🧰 AI Toolbox

AI Toolbox is a centralized platform that aggregates, categorizes, and recommends AI tools based on user needs.  
The goal is to help individuals, students, and professionals discover the right AI tools quickly and improve their workflow efficiency.

## 🌟 Features
- 📂 **Categorized AI Tools** – Browse tools by category (Writing, Coding, Design, etc.)
- 🔍 **Smart Recommendations** – Get AI tool suggestions tailored to your requirements
- 📈 **Trending & Recently Used** – See what’s popular and revisit your recent tools
- 🎨 **Modern UI/UX** – Clean and responsive design with horizontal sliders and premium/light theme
- 🔗 **Direct Redirects** – Jump directly to the chosen AI tool’s website

## 🏗️ Tech Stack

### **Frontend**
- React (Vite or CRA)
- Axios
- React Router

### **Backend**
- Spring Boot  
- Spring Web  
- Spring Security (JWT Authentication)  
- Spring Data JPA / Hibernate  

### **Database**
- MySQL  
- Organized schema, seed data, and migrations included

### **Storage & CDN**
- Local static folder (development)  
- Cloudflare CDN (production)

### **Deployment**
- Frontend → Vercel   
- Backend → Render   
- MySQL → Railway
